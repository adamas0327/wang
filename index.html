ABOUT

一只会陪你干活、会整活、会聊天的桌宠

单进程多实例架构 · 全部分身共享一套资源 · 表情全局互斥不撞脸

单进程多分身

分出 3 个、13 个分身都只在同一个主进程内，任务管理器永远只有一条程序，Alt+Tab 不被刷屏。

快捷方式收纳箱

把快捷方式拖到桌宠身上就吃掉收纳，隐藏启动器随时启动，单击启动、右键吐出到桌面。

13 表情互斥

同一时刻所有分身表情互不重复；自动轮换与手动点击切换都执行全局排重，13 只 13 种表情。

待机自动换表情

静置时按设定间隔自动随机换表情/动作，间隔可自定义；手动点击切换照常保留，两套逻辑不冲突。

一对一私聊

独立气泡聊天窗，像微信/QQ 一样收发；桑多涅傲娇人设全程在线，不弹出豆包主窗口。

一键换鼠标指针

动态 / 静态两套 Q 版木偶指针一键切换，指针大小 1-15 档实时放大，重启后保持。

智能互动全家桶

指哪打哪、拉回窗口、单击触发双击、呼叫豆包、淘气三档、巡逻间距——全都可开关可调速。

STORE

收纳箱 · 快捷方式吞吐系统

桌面游戏玩法：让它吞哪一个就吞进去，按一下就吐出来

拖进去吃掉

把桌面或文件夹里的快捷方式（.lnk/.url/.exe/.bat/.cmd）直接拖到桌宠身上，它就会吃掉并收纳起来，桌面瞬间清爽。

隐藏启动器

右键菜单 → 收纳箱 打开启动器列表：带图标与路径，单击直接启动程序，一个窗口管理所有收纳项。

按一下吐出

右键列表项即可吐出到桌面（快捷方式自动重建），也可一键全部吐出；收纳列表永久保存，重启不丢。

安全与兼容：桌面原件吞入时移入回收站（可随时手动恢复），吐出时自动重建快捷方式到桌面； 与 DeskBox 等桌面美化工具完全兼容——收纳箱接收标准文件拖拽，和桌面收纳盒互不干扰，可以同时使用。
CLONE

分身系统

最多 13 只，数量上限 = 表情素材数

功能说明
快速分身右键菜单「快速分身」1/2/3 一键分，或到上限后随机补满
收回分身「收回这个」只收回当前这只；「收回其他」保留当前、收回全部其余；最后一个分身永远收不回去
表情互斥同一瞬间所有分身的表情/待机动画互不重复；分身数超过 13 才允许重复并尽量错开
单进程架构所有分身运行在同一主进程内，资源（贴图/动画/帧缓存）全局共享只加载一份
独立行为每个分身独立移动、独立待机、独立随机动作，但共用同一套全局定时器（全进程仅 2 个）
巡逻间距「设置 → 分身巡逻间距」可调 50-600px，多分身移动中自动变速拉开距离
CHAT

一对一私聊 · 桑多涅傲娇人设

不弹出豆包主窗口，后台静默对话，前台只有宠物气泡窗

微信式气泡窗

独立窗口、气泡对话，固定大尺寸可拖拽缩放，收发一目了然；点击任意分身都可开聊。

傲娇人设绑定

固定启用桑多涅专属提示词：嘴硬心软、机械演算、执行官礼仪，口头禅还原官方语音风格。

人设可开关

「设置 → 角色人设」开关自由切换：桑多涅模式 / 普通对话模式。

接入方式：在「设置 → API Key」填入你的豆包（火山方舟）API Key 即可直连使用； 未填 Key 时聊天窗自动唤起本机豆包客户端转接对话。跨电脑使用时在设置里重填新电脑的 Key 即可。
